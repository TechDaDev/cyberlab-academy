# CyberLab Academy

Mission-based cybersecurity education and simulation platform.

## Project status
- Milestone 01A–01D: identity, access and platform foundation — implemented and locally verified.
- Milestone 02A: academic catalog backend (courses, modules, lessons, objectives, resources,
  draft/publish lifecycle) — accepted and merged.
- Milestone 02B: classes, instructor assignments, student enrollment and relationship-based
  lesson access — backend implemented; frontend and later phases pending.

The API contract is generated by the backend and committed to
[`shared-contracts/openapi.json`](shared-contracts/openapi.json). Frontend work targets that
contract, not guessed endpoints.

## Architecture
- `frontend/`: Next.js, TypeScript, Tailwind CSS, shadcn/ui.
- `backend/`: Python FastAPI, PostgreSQL, Alembic.
- `simulation-engine/`: TypeScript, deterministic browser simulations.
- `mission-content/`: Original, versioned module/mission data.
- `shared-contracts/`: OpenAPI and shared JSON schemas.
- `infrastructure/`: Local development and deployment configuration.
- `docs/`: Architecture, roles, security, milestone reports and implementation plans.

## Workflow
- **DeepSeek** — backend engineering: FastAPI, PostgreSQL, Alembic, contracts, security.
- **Arena AI** — frontend engineering: visual design, accessibility, responsive interaction.
- **Codex** — independent testing and security verification of each pull request.
- **ChatGPT** — architecture and project coordination.

Changes use feature branches and pull requests; nobody pushes to `main` directly. See
[`AGENTS.md`](AGENTS.md) for the binding rules.
